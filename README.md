# Image Recognition System

## Description
An Image Recognition System developed using Python, TensorFlow/Keras, OpenCV, and Flask to identify objects from uploaded images.

## Features
- Image Upload
- Object Recognition
- Prediction Display
- User-Friendly Interface

## Technologies Used
- Python
- TensorFlow/Keras
- OpenCV
- Flask
- HTML/CSS

## How to Run
1. Install dependencies
2. Run app.py
3. Open http://127.0.0.1:5000
